# Интерфейс Striped Skins по Figma

Основа: [макет пользователя](https://www.figma.com/design/7ZqpYdHWnQuAYr3YMWhbId?node-id=4-2).
Реализация оформляется отдельным stacked PR поверх `codex/pony-renderer-editor` (#5).

## Просмотрщик

Компактная шапка показывает документ и состояние правок, переключает просмотр/редактор,
открывает импорт и сохраняет PNG. Кнопка «Параметры скина» открывает немодальное окно:
модель остаётся доступной для вращения. В сравнении выбирается первый или второй документ;
редактор и импорт работают с выбранным скином. URL с подписанными параметрами сохраняется.

Параметры дополнены относительно иллюстративного макета: 13 рас (включая Human), все
шесть размеров, три морды, длина/форма хвоста, цвет свечения и восемь wearable ID.
Реальные аксессуары заменяют отсутствующие в MLP «жилет», «очки» и «копыта» из макета.
Раса/размер/аксессуары записываются в PNG; slim, крылья и водная форма — предпросмотр.

## Редактор

- Переключение **3D / Рядом / 2D**, в 2D остаётся небольшое живое 3D-превью.
- Кисть **B**, ластик **E**, пипетка **I**, перемещение **H**, размер **[ / ]**.
- **Ctrl/Cmd+Z**, **Ctrl/Cmd+Shift+Z** — отмена/повтор одного штриха.
- Размер и alpha кисти, палитра из настоящих цветов скина и добавление своих цветов.
- 2D: колесо/кнопки для масштаба, ПКМ либо пробел с перетаскиванием для панорамы,
  пиксельная сетка, UV-контуры, курсор кисти. **F** вписывает виды в окно.
- 3D: вращение, zoom, сброс, ракурсы и перспективная/ортографическая проекция.
- Панель частей: выбор поверхности, изоляция, скрытие ветки/отдельной геометрии,
  поиск и восстановление видимости. Скрытие не удаляет пиксели из экспортируемого PNG.

Импорт поддерживает файл, drag-and-drop и URL. При изменённом документе можно отменить
замену, сначала экспортировать текущий PNG или явно заменить. Ошибочный импорт сохраняет
текущий документ. Имя файла и признак правок сохраняются между маршрутами; повторный
импорт создаёт независимый документ. Локальное восстановление пикселей остаётся из #5.

Редактор загружается отдельным модулем. Обычные элементы и SVG-иконки собраны в небольшие
общие компоненты; дополнительных UI runtime-зависимостей нет. Шрифт Inter и исходные
UI-иконки из Figma хранятся локально в `public/design`. Источники и лицензия — там же.

## Проверка дизайна

Для реализации прочитаны полные design-context и скриншоты редактора `4:2`, просмотра
с параметрами `15:668` и плавающего 3D-превью `6:83`, а также структура файла и заметки
по взаимодействию. Затем Starter-лимит Figma MCP ограничил дополнительные запросы.
Окно импорта адаптировано к полученной визуальной системе и рабочим сценариям приложения.
Иллюстрации моделей/атласа заменены реальными динамическими данными, не изображениями макета.

Браузерные проверки охватывают немодальность настроек, переключение видов, инструменты,
панораму/zoom, ракурсы/проекции, замену документа, мобильную ширину, локальность ресурсов
и размеры всех использованных SVG. `/model-lab` остаётся отдельной диагностической
страницей для проверок генератора; основной пользовательский поток проходит через `/` и `/editor`.
