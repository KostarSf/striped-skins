# Развитие редактора пиксельной графики

Редактор сохраняет специализацию на Minecraft / Mine Little Pony скинах:
рисунок один и тот же в 2D и 3D, инструменты учитывают UV-развёртку,
служебные пиксели MLP защищены. Слои рисунка независимы от дерева геометрии.

## Этап 1 — многослойный проект

Реализовано:

- [x] Растровые слои и вложенные группы, активный слой, порядок отрисовки.
- [x] Создание, переименование, дублирование и удаление слоя / группы.
- [x] Перенос между группами и изменение порядка кнопками или drag-and-drop.
- [x] Видимость, непрозрачность, блокировка слоя / группы; блокировка прозрачности слоя.
- [x] Изолированное сведение групп и объединение с нижним растровым слоем.
- [x] Единая история рисования, метаданных и операций со слоями; undo/redo.
- [x] Проект `.striped`: точные RGBA, дерево, метаданные, история, палитра,
      инструменты, UV/сетка, 2D-вид, камера, поза, видимость частей и параметры вида.
- [x] Отдельные команды сохранения проекта и экспорта сведённого PNG.
- [x] Автовосстановление проекта и истории из IndexedDB, миграция старых снимков.
- [x] Защита несохранённого проекта при замене и закрытии вкладки.
- [x] Компактная шапка, меню приложения, панель слоёв и история; доступ с телефона.

Формат и ограничения описаны в [project-format.md](project-format.md).
История ограничена 100 операциями и бюджетом памяти; файл хранит всю оставшуюся
историю. При перезагрузке не восстанавливается незавершённый жест указателя:
последний сохранённый фрагмент штриха становится одной отменяемой операцией.

## Этап 2 — точное редактирование

Порядок соответствует зависимостям: сначала выделение, затем операции над ним.

- [ ] Маска выделения: прямоугольник, лассо, волшебная палочка, выбор по цвету.
- [ ] Добавление / вычитание областей, инверсия и отмена выделения.
- [ ] Ограничение всех инструментов выделением.
- [ ] Вырезание, копирование, вставка в новый слой; буфер обмена.
- [ ] Сдвиг на один пиксель, отражение, поворот на 90°, масштаб nearest-neighbor.
- [ ] Заливка связной области или всех совпадений, допуск цвета,
      источник — активный слой или видимый результат.
- [ ] Ограничение заливки UV-гранью, островом или частью модели.
- [ ] Замена цвета в выделении, слое или документе.
- [ ] Прямые, ломаные, прямоугольники и эллипсы: контур / заливка, предпросмотр.
- [ ] Пипетка с альфа-каналом и выбором источника: слой / сведённый результат.

Критерий готовности: правка участка скина без ручного перерисовывания;
все операции отменяются, сохраняются и одинаково отображаются в 2D/3D.

## Этап 3 — инструменты художника и работа с моделью

- [ ] Симметрия 2D с настраиваемой осью.
- [ ] Парные UV-области: ноги, крылья, уши; копирование между частями модели.
- [ ] Выделение UV-острова кликом по модели, подсветка общих UV-поверхностей.
- [ ] Продолжение широкого 3D-штриха через топологически связанные UV-швы.
- [ ] Круглая / квадратная кисть, штампы, стабилизация и pixel-perfect режим.
- [ ] Именованные палитры, импорт / экспорт, извлечение из изображения.
- [ ] Режим ограничения палитрой, редактирование цветовых рамп.
- [ ] Дизеринг, ступенчатые градиенты, осветление / затемнение по палитре.
- [ ] Маски слоёв и групп, обтравка по нижнему слою.
- [ ] Режимы наложения, начиная с Multiply для теней.

Критерий готовности: предсказуемые пиксельные края без размытия;
симметрия учитывает ориентацию UV, а новые свойства сохраняются в проекте.

## Этап 4 — рабочее пространство и варианты

- [ ] Референсы рядом с холстом и поверх него, прозрачность и выбор цвета.
- [ ] Сохраняемые пресеты камер и видимости частей.
- [ ] Контрольные версии и именованные снимки проекта.
- [ ] Шаблоны разрешения и стартовых групп «тело / грива / одежда».
- [ ] Варианты окраски через комбинации видимости слоёв.
- [ ] Настраиваемые сочетания клавиш, панели и размеры областей.
- [ ] Отдельные текстуры аксессуаров и другие ресурсы проекта.

## Сквозные требования

- Версионирование формата и миграции без молчаливой потери неизвестных данных.
- Защита служебных пикселей при рисовании, заливке и трансформациях.
- PNG — результат экспорта; сохранение исходного проекта выполняется отдельно.
- Сначала проверка корректности на 64×64, затем HD и несколько вложенных групп.
- Контроль памяти истории и перерисовка только изменённых областей при штрихе.
- Доступность клавиатурой и на сенсорном экране, понятное состояние блокировок.
